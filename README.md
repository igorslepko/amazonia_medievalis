## 🏰 О проекте

**Amazonia Medievalis** — это учебный интернет-магазин, стилизованный под средневековье. Создан специально для отработки навыков автоматизации тестирования с помощью **Playwright**.

В магазине есть:
- 🛒 Корзина-сундук (не корзина, а сундук! 📦)
- 🔥 Пиксельный факел в логотипе
- 📜 Индульгенции (при покупке 3+ — скидка 10%)
- 🐴 Запасная лошадь («никогда не знаешь, когда понадобится»)
- 🌐 3 языка (RU, EN, LA)
- 💰 3 валюты (₽, $, ⛃)

---

## 🎯 Цель проекта

**Отработать навыки написания автотестов на Playwright:**

- ✅ Page Object Model (POM) — структурированный подход
- ✅ FMT — функционально-модульное тестирование
- ✅ Работа с динамическими элементами
- ✅ Проверка состояний (скидки, корзина, смена языка/валюты)
- ✅ Параметризация тестов
- ✅ Allure-отчёты (опционально)
