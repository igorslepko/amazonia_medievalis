# amazonia_medievalis
SPA for test purposes and fun!
---

**Amazonia Medievalis** — это учебный интернет-магазин, стилизованный под средневековье. Создан специально для отработки навыков автоматизации тестирования с помощью **Playwright**.

В магазине есть:
- Корзина (сундук)
- Товары в разных категорияъ
- Система скидок
- Локализация
- Разные валюты
---

## 🎯 Цель проекта

**Отработать навыки написания автотестов на Playwright:**

- ✅ Page Object Model (POM) — структурированный подход
- ✅ FMT — функционально-модульное тестирование
- ✅ Работа с динамическими элементами
- ✅ Проверка состояний (скидки, корзина, смена языка/валюты)
- ✅ Параметризация тестов
- ✅ Allure-отчёты (опционально)

---

## Что тестировать

### Основные сценарии

| # | Сценарий | Описание |
|---|----------|----------|
| 1 | ✅ Добавление товара в сундук | Проверка, что товар появляется в корзине |
| 2 | ✅ Удаление товара из сундука | Проверка удаления и обновления суммы |
| 3 | ✅ Скидка за 3 индульгенции | Добавление 3+ индульгенций = 10% скидка |
| 4 | ✅ Смена языка | Проверка текстов на RU/EN/LA |
| 5 | ✅ Смена валюты | Проверка пересчёта цен (₽, $, ⛃) |
| 6 | ✅ Поиск товара | Проверка фильтрации товаров |
| 7 | ✅ Бегущая строка | Проверка текста акции на всех языках |
| 8 | ✅ Инквизиция | Клик по категории "Инквизиция" — модалка с угрозой |
| 9 | ✅ Очистка сундука | Подтверждение очистки и обновление состояния |
| 10 | ✅ Логотип-факел | Проверка, что GIF отображается |
